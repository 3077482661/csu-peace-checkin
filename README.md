# 平安打卡助手 · 下载与更新

本仓库仅发布安装包、更新清单及版本说明，源码不公开。

请在 [Releases](https://github.com/3077482661/csu-peace-checkin/releases) 下载安卓安装包。升级请直接覆盖安装，保留原账号，不要先卸载或清除数据。安卓1.6及更早版本需要先手动升级到1.7一次。

安卓1.7：首页“版本与更新”可手动检查新版，也可选择在非计费网络自动检查和下载。安装仍需本人在系统界面确认，默认关闭自动检查。

应用账号、会话及位置保存在使用者设备，不上传本仓库。GitHub更新检查不发送学校账号。网络限制可能使更新访问失败。

苹果版仍在构建验证，未签名IPA必须本人签名后才能安装；iOS不能保证指定分钟后台唤醒。

个人工具，非学校官方应用。学校当次接口决定是否允许打卡，只有学校确认才显示成功。应用内收款码用于完全自愿的创作者打赏。

协议适配来源：[barkure/csu_dk](https://github.com/barkure/csu_dk)，MIT声明随应用保留。校徽及创作者收款码不属于MIT源码授权范围。
